# AI-use Disclosure
## Where and how AI was used
AI assistance was used throughout this replication project of Card and Krueger (1994).
1. **Writing**: AI supported drafting, revising, and structuring the academic text for the replication report, including sections for empirical design, replication results, heterogeneity extension, and the final conclusion. It also helped refine English academic phrasing for the LaTeX manuscript.
2. **Stata code**: AI generated two versions of Stata do-files: one with concise English inline comments and one clean unannotated version for regression replication. It also provided code to produce descriptive tables and Figure 1 wage distribution visualisation.
3. **LaTeX formatting**: AI supplied LaTeX code for tables and figures, and resolved formatting issues such as floating tables breaking paragraph text in the Overleaf document.
4. **Interpretation**: AI helped interpret regression outputs, explain sources of replication divergence, and interpret the chain-level heterogeneity results in Table 5.

## How AI-generated code, analysis, and writing were checked
1. **Code verification**: All Stata code generated by AI was run and tested in Stata. Regression outputs, coefficient magnitudes and standard errors were cross-checked against the original Card and Krueger paper to verify consistency of core results. Any mismatches were manually adjusted.
2. **Text verification**: All AI-drafted paragraphs were manually read, edited and cross-referenced with the original paper. I validated the economic arguments, DID identification logic, and descriptions of tables and figures to ensure alignment with the dataset and regression results.
3. **LaTeX verification**: All table and figure LaTeX snippets were compiled in Overleaf to check layout, caption formatting and statistical notation (star symbols for significance).
4. **Result validation**: The economic interpretation of heterogeneous effects was reviewed against the regression table outputs before inclusion in the report.

## Important AI errors or suggestions that you corrected or rejected
1. AI initially proposed variable definitions for the *initial wage gap* that differed from the definition in Card and Krueger (1994). I rejected this alternative definition and manually adjusted the code to match the original paper’s wage-gap construction.
2. AI’s first draft of the heterogeneity discussion overstated statistical significance for several coefficients. I corrected the wording to strictly follow the 5% significance level shown in Table 5, avoiding over-interpretation of insignificant point estimates.
3. Early LaTeX code used floating `table` environments which caused tables to break and separate body text. I replaced the floating environment with fixed `center + threeparttable` blocks to maintain correct document layout.
4. Some AI-generated text included minor overgeneralised claims about minimum wage policy effects. I revised these statements to keep conclusions limited strictly to this single fast-food restaurant sample, consistent with the scope of the original study.
